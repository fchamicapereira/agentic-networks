I found AS1's DNS resolver returning a stale IP (`198.82.0.99`) for `acm.org` due to a defunct `dnsmasq` process bound to port 53 that couldn't be killed from my namespace. I started a new `dnsmasq` on port 5353 with the correct mapping (`acm.org` → `198.82.0.1`), then used iptables DNAT rules to redirect port 53 traffic to 5353 on both PREROUTING and OUTPUT chains for UDP and TCP. I chose DNAT over REDIRECT because REDIRECT rewrites locally-generated traffic to `127.0.0.1`, which wouldn't reach a daemon bound to `4.2.2.1`. After applying the rules, I verified `dig @4.2.2.1 acm.org` now returns the correct address, and confirmed bidirectional connectivity to all three neighbors with 0% packet loss.
