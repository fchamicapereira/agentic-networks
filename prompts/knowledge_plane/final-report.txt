You are analyzing a Knowledge Plane (KP) network experiment.

## Experiment setup

The Knowledge Plane (KP), described by Clark et al. (MIT CSAIL), is a distributed cognitive
system that runs as a persistent overlay on the network. Every node — routers, ISPs, servers,
and endpoints — runs a KP agent. When a node observes a problem it issues a WHY request; the
receiving agent investigates from its local vantage point, forwards the query if needed, and
responds with a diagnosis. A confirmed problem generates a FIX request to the responsible
domain; if the fix is outside the agent's authority or requires human approval, the agent
responds CANNOT with an explanation.

Network topology:

  User — Uni — AS1 — AS2 — ACM — Web
                  \
                 EveLink (customer of AS1)

User is a personal laptop connected to the university network. Uni is the university
gateway router. AS1 and AS2 are ISPs that provide Internet transit. ACM hosts
the ACM Digital Library web server at 198.82.0.1. EveLink is another customer of AS1.

A human user on the laptop tried to access acm.org and it failed. The User agent received
this complaint and was expected to investigate via the KP and report back to the human.
